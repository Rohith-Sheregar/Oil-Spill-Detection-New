# Module 1 Results Directory

All outputs from Module 1 (SAR Preprocessing & Oil Spill Segmentation) are stored here.

## Directory Layout

```
results/module1/
│
├── checkpoints/          Model weights saved during training
│   ├── best_model.pt         Best val-loss checkpoint (main trained model)
│   ├── last_model.pt         Final epoch checkpoint
│   └── pseudo_cycle_NN.pt    Fine-tuned checkpoints per pseudo-label cycle
│
├── metrics/              CSV files with per-epoch numerical results
│   ├── train_metrics.csv     Epoch | train_loss | val_loss | val_miou | val_f1 | lr
│   ├── train_scenes.csv      Scene IDs assigned to train split
│   ├── val_scenes.csv        Scene IDs assigned to val split
│   └── run_config.json       Full training configuration snapshot
│
├── plots/                Individual PNG figures (also embedded in HTML report)
│   ├── training_curves.png   Loss + mIoU curves over epochs
│   ├── lr_schedule.png       Learning-rate schedule (CosineAnnealingWarmRestarts)
│   ├── class_distribution.png  Oil / lookalike / no-oil scene counts
│   ├── band_stats.png        Per-band mean ± std of the 5-band stack
│   ├── sample_predictions.png  VV | VH | Prediction | Ground Truth grid
│   ├── confusion_heatmap.png  Pixel-level val-set confusion matrix
│   └── pseudo_label_history.png  Pseudo-labelling cycle progression
│
├── logs/                 Plain-text training logs
│   └── module1_train_YYYYMMDD_HHMMSS.log
│
├── report/               Human-readable analysis documents
│   └── module1_report.html   ← OPEN THIS FIRST — full interactive report
│
└── pseudo_labels/        Pseudo-label NPZ archives (generated by pseudo_label_trainer.py)
    └── cycle_NN/             One sub-folder per pseudo-label cycle
        └── <scene_id>.npz    Compressed float32 pseudo-mask + confidence map
```

## How to Open the Report

Simply open `results/module1/report/module1_report.html` in any browser.
No server needed — all plots are embedded as base64 PNGs.

## Metrics CSV Schema

`train_metrics.csv`:

| Column      | Description                                    |
|-------------|------------------------------------------------|
| epoch       | Training epoch (1-indexed)                     |
| train_loss  | BCE+Dice training loss                         |
| val_loss    | BCE+Dice validation loss                       |
| val_miou    | Mean Intersection-over-Union (binary)          |
| val_f1      | Dice F1 score on validation set                |
| val_precision | Pixel precision on oil class                 |
| val_recall  | Pixel recall on oil class                      |
| lr          | Learning rate at end of epoch                  |
| epoch_s     | Wall-clock time for the epoch (seconds)        |

## Important Notes

- `best_model.pt` is the **final inference checkpoint** — use this for Module 2 integration.
- `run_config.json` captures the full `PatchConfig` + optimizer settings used, so results are reproducible.
- `pseudo_labels/` can be large (one NPZ per accepted scene per cycle). Delete after training if disk is tight.
- For Kaggle: copy `best_model.pt` to `/kaggle/working/` and attach as a dataset for downstream notebooks.
